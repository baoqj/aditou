# Aditou 数据可视化 v1

学生从「我的进步」进入 `/learn/progress`。教师和机构从「报告」进入 `/org/main/manage/reports`。机构所有者首次使用时，在「数据与权限」创建机构。负责教师在同一栏目选择班级、输入机构所有者邮箱并授权。机构报表显示获授权班级的汇总，教师在「我的班级」查看所负责班级的学生明细。教师可撤回授权，后续查询和导出立即应用新范围。

| 指标 | 计算口径 |
| --- | --- |
| 有效提交 | 服务端确认的尝试，按唯一提交去重。考试未作答题不计练习提交。 |
| 首答／重练 | 同一学生、逻辑题目、语言在保留历史内第一次提交计首答，后续计重练。报告标注外部帮助未知。 |
| 已批客观正确率 | 已批客观题正确数除以已批客观题数。人工题、待批和未发布结果各自呈现。 |
| 得分率 | 已批所得分之和除以对应满分之和。部分得分保留。 |
| 已记录练习时长 | 前台题内区间，90 秒无活动后暂停，实际播放进度提供听题区间。多设备按学生合并区间，归类优先级为答题、听题、阅读。 |
| 作业完成 | 到期批次内已完整提交任务数除以冻结目标任务数。提交、批改、按时和逾期分别呈现。旧名单标注为上线时重建。 |
| 课堂分钟 | 每课次确认的时间区间取并集，再对课次求和。教师人时按每位教师取并集后求和。 |
| 练习参与 | 已提交学生按稳定 learner_id 去重。记录覆盖另列。 |

统计查询以日期、时区、题目语言、目标年级、来源、技能和题型筛选答题及练习时间。授课按区间发生日期，作业按到期批次和班级年级／语言筛选。时间默认按多伦多日历划分。图表和表格共用 `aditou-analytics-v1`，显示数据更新时间。汇总 JSON 导出使用同一查询并记录审计事件。

现阶段展示当前可核实的事实。历史计时标为部分数据，排课计划、可靠出勤、校准后的可比趋势及固定群体和延后变式分析需要进一步的业务事实。课堂实时刷新沿用现有 2.5 秒轮询。确认授课可录入多个实际区间，暂停由录入者排除。家庭私有练习只在学生本人范围呈现，机构模式提供班级汇总和聚合下钻。

## 验证

- `npm run build`。
- `node --test tests/analytics.test.mjs tests/i18n.test.mjs`。覆盖汇总分母、历史首答、成绩发布、授权撤销、隐私、时长去重和夏令时。
- 在隔离本地 D1 应用迁移后，使用 `tests/analytics-fixtures.mjs` 生成本地数据并运行 `tests/analytics-browser.mjs`。验证三角色真实提交、作业状态、授课、导出、图表下钻与响应式布局。
- 浏览器验收截图位于 `artifacts/analytics/`。截图使用本地测试数据。
- 旧注册和 TTS 集成测试依赖 Resend 和 Workers AI。本次隔离环境没有启用这两个外部绑定，相关旧用例未通过。
