# Studio 题目与音频编辑工作区

按用户要求，以两栏替换题目下拉选择：左侧展示可独立滚动的完整清单，提供关键词、年级、内容语言及状态筛选；右侧显示选中题目编辑区。桌面／Pad 保持两栏，手机将列表置于上方，选择题目后滚动到编辑区。

右侧依次为题目文本、TTS 设置、录音／上传、历史音频。文本包含标题、学生可见内容、朗读稿与教师备注。修改保存为新题目版本，原作业和提交引用保持不变。生成 TTS 或上传音频前如有修改，先保存新版本，音频关联新题目 ID。

TTS 通过 Cloudflare AI Gateway，模型白名单为 Grok TTS 与 MeloTTS；前者提供 Ara / Eve / Rex / Sal / Leo，后者采用模型标准声线。模型与声线按题目持久化。重新生成使用新的请求 ID 与对象键，并跳过 Gateway 缓存；相同请求 ID 重试复用结果，旧音频保留。

录音申请期间／录音中／服务端操作中锁定切题，录音结束停止麦克风。存在未保存文本或本地片段时切题要确认；页面卸载前提示保存。音频先作为草稿，试听后单独发布。英法界面继续使用 i18n，内容语言和界面语言独立。
